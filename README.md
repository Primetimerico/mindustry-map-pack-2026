## FAQ

**Where does Mindustry store maps?**  
Windows: %appdata%\Mindustry\maps\. The installer script handles this automatically.

**Are PvP maps balanced for equal starts?**  
Yes — PvP maps use mirrored terrain and equal resource distribution.
