## 🛠️ Installation Troubleshooting

### "I can't find the %appdata% folder"
This is a hidden system folder. The easiest way is to:
1. Press the **Windows key** + **R** on your keyboard
2. Type `%appdata%` in the box
3. Press **Enter**
You'll now see the folder open automatically.

### "Mindustry doesn't show my maps"
Double-check that you placed the `.msav` files directly inside the `maps` folder. Sometimes users accidentally put them in a subfolder, which Mindustry ignores.

### "The maps load but look blank"
This usually means the game needs to load the map data. Close and restart Mindustry, then try loading the map again. If it persists, verify your game version is up to date (the pack works with version 7.0 or newer).

### "Can I uninstall?"
Yes! Simply delete the map files from the `maps` folder. Your other game data won't be affected.
